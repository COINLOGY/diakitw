# diakitw 0.4.5

Репозиторий дистрибутивов и сайта, **не репозиторий исходников приложения**.

- [Центр загрузок](https://coinlogy.github.io/diakitw/)
- [Предварительный выпуск v0.4.5](https://github.com/COINLOGY/diakitw/releases/tag/v0.4.5)

Пять сборок: macOS arm64 и Intel (DMG), Android (debug APK), Windows x64 (portable ZIP), Linux x64 (portable tar.gz). Общий ZIP содержит только эти пять файлов, без iOS, SDK и исходников проекта.

## Изменения и проверки

macOS: исправлена геометрия общей верхней полуокружности, подписи и компактные размеры. Android и desktop: адаптивная компоновка приборов и подписи; это не тот же дефект полной окружности. Возможности платформ не эквивалентны.

Для публичной distribution-ревизии macOS пересобран с remapping путей и удалением отладочных символов; helpers подписаны перед app. Windows/Linux изменён только текст локального пути в VERIFICATION-RU.md, остальные файлы и режимы сохранены. APK не изменён. Контрольные суммы новые: используйте приложенные SHA256SUMS и release-manifest.json, не суммы прежних локальных архивов.

Проверены read-only DMG, архитектуры, ресурсы, ad-hoc подписи и arm64 offline self-check; шесть native check executables завершились успешно. Intel runtime не проверен. Для Windows/Linux подтверждены PE/ELF и ASAR; запуск на целевых ОС не проверен. Android APK ранее проверен на API30 ARM64, включая 14 конфигураций интерфейса; не на всех телефонах/API.

## Ограничения доверия

macOS 14+: ad-hoc, без Developer ID и notarization. Android 8+: debug-подпись, не Play Store. Windows: без Authenticode. Linux: подпись издателя не заявлена, требуется подходящая графическая среда и зависимости Electron. Не отключайте защиту ОС или Chromium sandbox. SHA-256 подтверждает байты, а не безопасность приложения.
