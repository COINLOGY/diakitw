## Установка / Installation

- **macOS 14+**: выберите arm64 или x86_64 DMG, скопируйте приложение в Applications / choose the matching architecture and copy to Applications. Ad-hoc, **not notarized**, not Developer ID.
- **Windows 10/11 x64**: распакуйте весь ZIP и запустите EXE / extract the entire ZIP and run the EXE. **No Authenticode**.
- **Linux x64**: распакуйте tar.gz в графической сессии, запустите `diakitw` / extract and run in a desktop session; glibc, GTK/NSS/ALSA required. Do not disable the sandbox.
- **Android 8+**: сохраните отчёты, удалите старое приложение, затем установите APK системным установщиком / export reports, uninstall the old app, then install the APK using the system installer. See mandatory warning above.
- **iOS 16+**: device APP ZIP **UNSIGNED, не IPA и не автоматическая установка / not an installable IPA, no automatic installation**. Requires developer signing/provisioning. Simulator ZIP is for Xcode Simulator; SOURCE ZIP is the iOS project. No TestFlight/App Store release.

Не отключайте защиту ОС / do not disable OS security. Compare downloaded files with `SHA256SUMS`; checksums are not independent publisher signatures.
