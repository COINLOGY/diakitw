# diakitw 0.5.4 (54) — preview / candidate

Пять установочных/portable-пакетов: macOS arm64 и Intel, Windows x64, Linux x64, Android. Дополнительно: iOS unsigned device APP, simulator APP и SOURCE; unsigned APP **не является устанавливаемым IPA**, не App Store/TestFlight. Полный source ZIP соответствует тегу v0.5.4. Предыдущие релизы сохранены.

## Обновления / Updates

Проверка при foreground и вручную, каналы preview (по умолчанию) и stable, неблокирующее предложение и «Позже». Фиксированный feed: https://coinlogy.github.io/diakitw/updates/v1.json . Публикуется только preview; отсутствие stable не доказывает актуальность установленного stable-клиента. Старым клиентам 0.5.3 и ранее нужна **однократная ручная установка** первого выпуска с checker.

Только открытие браузера: приложение не скачивает, не проверяет hash/подпись скачанного файла и не устанавливает обновление автоматически. SHA256SUMS позволяет ручную проверку байтов, но не заменяет подпись издателя. Feed не имеет независимой криптографической подписи. iOS не устанавливает обновления; открытие страницы релиза предусмотрено клиентом, но unsigned iOS asset исключён из общего feed: строгие Desktop/Android parsers допускают только пять installer-platform keys. iOS материалы доступны вручную на странице релиза.

## Проверки и ограничения

Mac: CI build, DMG/signature/privacy gates, offline self-check обеих архитектур (Intel через Rosetta); ad-hoc, без Developer ID/notarization. Не заявлены physical Intel/oldest-OS acceptance или реальное click-through обновления.
Windows/Linux: проверены архивы, app/runtime parity и official Electron notices; целевые GUI/runtime и обновление поверх старой установки не проверены. Windows без Authenticode; Linux portable, не отключать sandbox.
Android: APK alignment, v2/v3 подпись и metadata проверены; прежняя debug identity, не store release; целевой GUI/real install не проверен.
iOS: production device/simulator build, 6 simulator XCTest и fixture smoke прошли; нет physical iPhone acceptance. Device APP unsigned; simulator не для телефона.
