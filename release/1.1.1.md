# diakitw 1.1.1

Первый выпуск новой линии. Отсчёт версий начинается с 1.1.1: всё, что было
сделано в ветке 1.0.x, включено сюда, прежние выпуски сняты с публикации.

## Что внутри

**Парк серверов (macOS)**

- измеренная история за час: 121 точка на 30-секундном опросе, не более 720 точек на 5-секундном
- история переживает перезапуск приложения: `~/Library/Application Support/macdir/history/`, атомарная запись, права `0600`, предел 1 МиБ
- подписи осей: `100 / 50 / 0 %` для CPU, максимальная достигнутая скорость для сети, три отметки времени
- подсказка под курсором на всех графиках: время замера и значение с единицами (`М/с`, `К/с`)
- оповещения по переходам: офлайн после N сбоев, CPU выше порога, диск ниже порога с гистерезисом +5 %, уведомление о восстановлении
- история диска и аптайма, число перезагрузок, доступность
- экспорт CSV через системный диалог сохранения
- интервал опроса 5–60 с, переиспользование SSH-соединения, сбор истории в фоне
- подсветка включённых режимов, адрес выхода рядом со страной в меню-баре и в шапке окна

**Android** — встроенная карта и геолокация, закрытие информационных окон при сворачивании, настоящая версия в User-Agent, сброс суточного лимита провайдера при смене сети.

**Desktop (Windows, Linux)** — тест интернета, диагностика, обзор парка серверов.

**iOS** — только компиляция и тесты, установочного файла в выпуске нет.

## Подпись и ограничения

- macOS: ad-hoc, без Developer ID и нотаризации. Gatekeeper может потребовать подтверждения; отключать защиту не нужно.
- Windows: без Authenticode, SmartScreen может предупредить.
- Android: тот же сертификат, что у линии 1.0.x — обновление поверх 1.0.x проходит. С 0.5.x установка поверх невозможна: удалите старое приложение, сохранив данные.
- iOS: только компиляция, архив не публикуется.
