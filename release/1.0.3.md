# diakitw 1.0.3 (build 103) — предварительный выпуск

Сборки: Android 8.0+, Windows x64, Linux x64, macOS Apple Silicon / Intel. iOS 1.0.3 только компилируется и тестируется: установочного iOS-файла в GitHub Release, на сайте и в канале обновлений нет.

- Android: карточка батареи убрана; увеличены страна и город, встроена карта при наличии координат провайдера. Подписан тем же сертификатом, что 1.0.1/1.0.2 (SHA-256 `d9298271dcb4e32856abdc2111b35ae43b7770b1c9fbfefa66100e899a58abc8`). Обновление поверх 1.0.1/1.0.2 возможно через системный установщик с подтверждением; с 0.5.x требуется сохранить данные и переустановить приложение — настройки могут потеряться. Нативный offline probe и проверки обновлятора прошли в CI; полный переход на физическом устройстве не проверен.
- Windows/Linux: тест интернета и инструменты диагностики расположены в панели; опасные сетевые действия требуют согласия. Portable-архивы и ресурсы проверены в CI, запуск GUI на целевых ОС не проверен. Windows EXE **без Authenticode**: SmartScreen может предупредить или заблокировать; не отключайте защиту. Linux требует графическую среду и GTK/NSS/ALSA, исполняемый бит в архиве сохранён.
- macOS: индикаторы и флаг страны VPN-выхода в строке меню. DMG доступны для arm64 и x86_64 только с ad-hoc подписью, **без Developer ID и нотариализации**: Gatekeeper может отклонить обычную установку. Не отключайте защиту. Установленный GUI и Gatekeeper acceptance на устройстве не проверены.

Для установленной macOS 1.0.2 в релизе есть дополнительные имена DMG без `-unsigned-`: они побайтно идентичны основным ad-hoc DMG, но соответствуют строгому формату прежнего обновлятора. Это **не** доверенная подпись или нотариализация.

Подписание Windows через SignPath и выпуск macOS с Developer ID запрошены, **но ещё не одобрены**; обещаний беспрепятственной установки нет. Улучшения после одобрения будут отдельным следующим выпуском.

Проверка обновлений может предложить и скачать файл, но Windows/Linux/macOS устанавливаются вручную; Android передаёт APK системному установщику. Не путайте проверку версии с автоматической установкой. Сверяйте скачанные файлы с `SHA256SUMS-1.0.3.txt` и размерами в README.
