# diakitw 1.0.2 (build 102) — предварительный выпуск

Сборки: Android 8.0+, Windows x64, Linux x64, macOS Apple Silicon / Intel. Флаг страны VPN-выхода расположен после показателей в строке состояния macOS; обновлены проверки версии и платформенные сборки. iOS 1.0.2 только компилируется и тестируется: установочный iOS-файл не публикуется.

**Установка и обновление**
- Android: APK подписан тем же release-сертификатом, что и 1.0.1 (SHA-256 `d9298271dcb4e32856abdc2111b35ae43b7770b1c9fbfefa66100e899a58abc8`). Обновление 1.0.1 → 1.0.2 допускает установку поверх через системный установщик с подтверждением. Старые APK 0.5.x подписаны другим ключом: перед установкой сохраните данные и удалите старую версию, возможна потеря настроек. Проверка на физическом устройстве не проводилась.
- macOS: сборки имеют только ad-hoc подпись, **без Developer ID и нотариализации**. Gatekeeper может отклонить установку; не отключайте защиту ради запуска. Установленный GUI на целевой ОС не проверялся.
- Windows: portable ZIP без Authenticode; SmartScreen может предупредить или заблокировать. Не отключайте защиту. Работа GUI на целевой Windows не проверялась.
- Linux: portable tar.gz, исполняемый бит сохранён; нужны графическая среда и GTK/NSS/ALSA. Работа GUI на целевой Linux не проверялась.

Проверка наличия новой версии не равна автоматической установке: Windows, Linux и macOS обновляются вручную; Android передаёт проверенный APK системному установщику. Полный цикл обновления 1.0.1 → 1.0.2 на физическом устройстве пока не проверен.

Сверяйте скачанные файлы с `SHA256SUMS-1.0.2.txt`. Исходники и проверенные CI-сборки привязаны к commit `3e4d763cbfb7a7749d0d0d0769b47635b352c5d7`.
