# diakitw 1.0.1 (build 101) — предварительный выпуск

Сборки для Android, Windows x64, Linux x64 и macOS (Apple Silicon / Intel). Код iOS 1.0.1 компилируется и тестируется отдельно; **iOS-файлы в этот релиз не включены**. Исходный commit: `384eecf93db27c101e76a32315f3d8d8da6081ee`.

**Что изменилось:** флаг страны рядом с IP, обновлённые сетевые индикаторы, единая версия 1.0.1/101 и проверки обновлений. Файлы и их SHA-256 приведены в `SHA256SUMS-1.0.1.txt`.

## Установка и ограничения

- **Android:** `diakitw-android-1.0.1.apk` подписан новым постоянным ключом (сертификат SHA-256 `d9298271dcb4e32856abdc2111b35ae43b7770b1c9fbfefa66100e899a58abc8`). Поверх APK 0.5.x со старым сертификатом установить нельзя: сохраните нужные данные, удалите старое приложение и установите 1.0.1 заново. Данные/настройки могут потеряться. Приложение проверяет APK по размеру, SHA-256 и закреплённому сертификату перед передачей системному установщику; Android может требовать подтверждения. Реальный переход 1.0.1 → следующая подписанная версия ещё не проверен.
- **Windows x64:** переносимый ZIP, распакуйте и запускайте `diakitw.exe`. Authenticode-подписи нет; запуск на целевой Windows и автоматическая замена EXE не подтверждены. Не отключайте SmartScreen или антивирус ради запуска.
- **Linux x64:** переносимый tar.gz, при распаковке сохраняется исполняемый бит. Нужны графическая сессия и системные GTK/NSS/ALSA; проверка GUI на целевой ОС и автоматическая установка не проводились. Не отключайте sandbox ради запуска.
- **macOS 14+:** отдельные DMG для arm64 и Intel. Сборки имеют только ad-hoc подпись — **Developer ID и нотариализации нет, Gatekeeper может отклонить установку**. CI проверил образы и автономный self-check обеих архитектур, но не установленный GUI. Не отключайте Gatekeeper ради запуска.
- **iOS:** только компиляция/тестирование; в этом релизе нет IPA или другого установочного файла.

Проверка новой версии в приложениях не равна автоматической установке. До появления доверенной подписи и испытания установки на целевых ОС обновление Windows/Linux/macOS остаётся ручным. Старым Android-клиентам не предлагается несовместимый APK нового поколения подписи.

Проверенные сборки GitHub Actions: Android `43711561698`, Windows/Linux `43711561727`, macOS `43715079287`. Это **предрелиз** для проверки, не обещание беспрепятственной установки на всех ОС.
