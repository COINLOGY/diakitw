# Security / Безопасность

0.5.2 is a preview, not a security-certified release. Checksums establish byte
identity, not absence of vulnerabilities/backdoors. No such certification is claimed.

Do not post credentials, SSH configuration, private addresses or unredacted logs
in issues. Use GitHub private vulnerability reporting if enabled; otherwise open
an issue requesting a private reporting channel without exploit secrets or data.
There is no guaranteed response time. Do not disable OS security or Chromium sandbox.

macOS is ad-hoc signed, not notarized; Windows has no Authenticode; Android uses
a debug certificate. Do not use these candidates for security-critical production.
Only connect to servers you administer and review diagnostic actions before running.
