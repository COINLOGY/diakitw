Как измеряются показатели

CPU — загрузка всего компьютера по разнице счётчиков. RAM: Linux — MemTotal − MemAvailable; Windows — физическая память минус свободная. SWAP: Linux — SwapTotal − SwapFree; Windows — фактическое использование файлов подкачки / текущий выделенный объём, не committed memory. При нулевом объёме процент не определён.

Диск — занятость файловой системы / в Linux или системного тома домашней папки в Windows, не здоровье накопителя. Батарея — первая доступная батарея. Сеть — байты выбранного интерфейса за фактическую монотонную секунду, интерфейсы не суммируются. После паузы, сброса счётчика и в первом отсчёте — Н/Д. Пробелы графика означают отсутствие измерения. Стрелочные шкалы RX/TX показывают реальные MiB/s с адаптивным диапазоном, не процент неизвестной пропускной способности. Это наблюдение трафика, не тест скорости интернета.

Опрос приостанавливается при потере фокуса, сворачивании или закрытии окна. Внешний IP и география получаются одним HTTPS GET https://aia.emcx.pro/diakitw-api/geo — 2ip через EMCx, без query и токена в приложении. Запросы при открытии активного окна, изменении интерфейсов/маршрутов (задержка 2 секунды) и каждые 60 секунд; минимум 10 секунд между попытками даже при повторном фокусе. Серверный кэш 1 час; общий бюджет 300 запросов в день / 9000 в месяц на всех клиентов, не на каждую установку. Поэтому география может обновиться позже IP/VPN; мгновенное определение не гарантируется. Таймаут 5 секунд, ответ до 16 KiB, redirects запрещены. Только при ошибке геосервиса используется существующий IP-only HTTPS api.ipify.org (5 секунд / 128 байт), география тогда Н/Д; ответы разных IP не объединяются. При отмене fallback не запускается. EMCx и 2ip видят IP интернет-выхода и сетевые метаданные; при fallback их видит ipify. Ключ 2ip хранится только на сервере. Без cookies, учётных данных, локальных адресов, показаний, файлов и фоновых запросов. IP и география хранятся приложением только в памяти. Это приблизительная геолокация интернет-выхода, не GPS: VPN может показывать другой город/страну. При отсутствии данных — Н/Д. Кнопка карты открывает HTTPS OpenStreetMap в браузере (© OpenStreetMap contributors): сайт получит IP и координаты/название страны. Для страны без города используется поиск страны, не выдуманная точка. Карта доступна только для актуальных данных. Ошибка или пауза не превращает последний IP в текущий. В меню доступны системный терминал и диспетчер задач. Для самых нагруженных процессов нажмите столбец CPU и выберите сортировку по убыванию; автоматическая сортировка не гарантируется. Отсутствующие программы отключены с причиной, ничего не устанавливается. Сканирования каталогов, очистки и стресс-тестов нет.
