# diakitw 0.5.5a — Windows x64 / Linux x64

Накопительный portable-выпуск, build 55: сохранены все функции 0.5.2 и география 2ip через EMCx. Expressive v4: дуга 7/9 прежней толщины, основание стрелки 10, тёмная ступица с цветной обводкой; размещение приборов сохранено. Это отдельное desktop-приложение, не полный перенос функций macOS.

## Запуск
Windows: распакуйте весь ZIP, запустите diakitw.exe. Не отделяйте EXE от runtime/resources. Требуется Windows 10/11 x64 и штатный Windows PowerShell/CIM; предпочтительна поддерживаемая Windows 11. Node/npm устанавливать не нужно. Издатель не подписан Authenticode: при блокировке не отключайте SmartScreen/антивирус, проверьте источник и SHA-256, обратитесь к администратору.

Linux: распакуйте `tar -xzf diakitw-0.5.5a-linux-x64.tar.gz`, в полученной папке запустите `./diakitw` обычным пользователем в графической сессии. Нужны x86-64 glibc, GTK/NSS/ALSA и рабочий Chromium sandbox. Это tar.gz с runtime, не AppImage/DEB/RPM. Не запускайте root, не применяйте --no-sandbox и не меняйте setuid/политику безопасности. При запрете namespaces/AppArmor обратитесь к администратору. Программа не устанавливает системные службы или инструменты.

## Сохранённые функции
- CPU всего компьютера: дельты счётчиков, не CPU одного процесса; Linux без двойного учёта guest.
- RAM: Linux MemTotal − MemAvailable; Windows физическая минус свободная память.
- SWAP рядом с RAM: использовано/текущий выделенный объём, GiB и процент. Windows — фактический Win32_PageFileUsage, не committed memory. Нулевой знаменатель: процент Н/Д, без стрелки.
- Диск: занятость файловой системы / Linux или корневого тома домашней папки Windows, не сканер/здоровье SSD.
- Батарея: первая доступная, процент и состояние; отсутствие — Н/Д.
- Выбранный сетевой интерфейс: RX/TX за реальный интервал, график 60 секунд, максимум 121 точка. Интерфейсы не суммируются; смена интерфейса и пауза очищают историю.
- Ресурсные приборы: верхние 180°, только 0/50/100%; сеть — фактические MiB/s с адаптивным диапазоном, не speedtest и не процент ёмкости канала. Основные значения без ведущих нулей. Неизвестное — без стрелки. Батарея при полном заряде зелёная.
- Числа слева, приборы справа; компактные одинаковые карточки. Размер Canvas кэшируется до resize, события объединяются, дуги 1–3 сегмента. На узком экране/большом шрифте доступна вертикальная прокрутка.
- Опрос примерно раз в 2 секунды после завершения предыдущего; без перекрытия. PowerShell: 7 секунд/256 KiB, отмена при паузе. Нет SSH, сканера/очистки диска, стресса, трея, автозапуска, speedtest или Android-функций.

## Внешний IP, страна, город, приватность
При активном окне отправляется фиксированный HTTPS GET `https://aia.emcx.pro/diakitw-api/geo`, без query и токенов. EMCx получает IP интернет-выхода и через серверную интеграцию 2ip возвращает IP/страну/опциональный город одним ответом. Ключ 2ip остаётся только на сервере и не включён в приложение. Дополнительные nullable region, code, timezone, lat/lon и ASN проверяются, но не все выводятся на главном экране. Отсутствие географии не является ошибкой IP и не запускает дополнительные запросы.

Это приблизительное положение интернет-выхода, НЕ GPS и НЕ положение компьютера. VPN/split tunnel/прокси меняют путь. Названия приходят на языке провайдера. Серверный кэш — 1 час; бюджет 300 запросов в день / 9000 в месяц общий для всех клиентов, не на каждую установку. Кэш и бюджет могут задержать географию; мгновенное обнаружение изменения VPN не обещается. Операционная доступность/квоты зависят от сервера, не гарантируются приложением.

Основной запрос: 5 секунд на весь ответ, максимум 16 KiB, без redirects/cookies/авторизации/ключа. Только после ошибки основного геосервиса используется сохранённый IP-only транспорт `https://api.ipify.org/` (ещё максимум 5 секунд, 128 байт). На успешном ответе с nullable географией и при отмене fallback не вызывается. IP fallback полностью заменяет прежнюю пару IP/география: страна, город, координаты и ASN становятся Н/Д; геоданные разных адресов не смешиваются. При отказе обоих сервисов последние данные остаются явно устаревшими, карта отключена.

Автоматически при входе в активное окно, изменении интерфейсов/маршрутов (debounce 2 секунды), резервно каждые 60 секунд; минимум 10 секунд между попытками даже при повторном фокусе. Один lookup одновременно; при blur/hide/minimize/close/quit или изменении маршрута запрос отменяется, старые ответы и ошибки отвергаются по generation/revision. Фонового сервиса нет.

EMCx получает внешний IP и сетевые метаданные HTTPS; 2ip получает запрашиваемый внешний IP через EMCx; ipify получает IP и метаданные только при fallback. Не отправляются имя компьютера, локальные адреса, файлы, показания ресурсов, координаты GPS или команды. IP/география хранятся приложением только в памяти; Electron может хранить обычный локальный профиль. Приложение не сохраняет raw provider errors и не показывает ответ сервера как HTML. Ошибки отображаются общим статусом.

Кнопка «Карта ≈ ↗» открывает только HTTPS OpenStreetMap в системном браузере, по проверенным координатам интернет-выхода. Если есть только страна, «Карта страны ≈ ↗» выполняет поиск страны без выдуманной точки. Встроенных тайлов и фоновой карты нет. При клике OpenStreetMap получает IP и координаты/поисковый запрос. © OpenStreetMap contributors; атрибуция на сайте OpenStreetMap. Неактуальные данные не открывают карту.

Интеграция использует предоставленный владельцем контракт EMCx/2ip; активация сервера и успешная авторизация сообщены координатором релиза. Клиентская сборка не меняет сервер, тариф, ключи или условия провайдера и не проверяет их повторными live-запросами. Никаких платежей или новых учётных записей. GeoJS больше не вызывается. Провайдеры могут ограничить или прекратить доступ; готовые локальные сборки не означают отдельного юридического одобрения публичного перераспространения API.

## Меню и системные инструменты
Используйте меню приложения либо компактную кнопку «⋮ Меню». Windows: штатный System32 cmd.exe с фиксированным /D (без AutoRun) и Taskmgr.exe. Нестандартный SystemRoot вне пути вида X:\Windows отключает инструменты. Linux: поиск только фиксированных путей /usr/bin для GNOME Terminal/Monitor, KDE Konsole/plasma-systemmonitor/ksysguard, XFCE terminal/taskmanager, MATE, LX и xterm. У исполняемого Linux-файла проверяются системное владение и отсутствие записи для группы/остальных. Отсутствующий инструмент отключён с причиной. Установка не выполняется.

Для самых нагруженных процессов в открытом диспетчере нажмите столбец CPU и выберите сортировку по убыванию. Автоматическая сортировка не обещается. Открывается отдельное системное приложение, которое остаётся открытым после закрытия diakitw. Renderer не может передать командную строку, путь, аргументы или произвольный URL: только фиксированные enum-команды через проверенный IPC.
