ПРОВЕРКА ЦЕЛОСТНОСТИ

Сначала SHA-256.
Затем установка.

Сравните весь hash со значением выбранной сборки. Совпадение подтверждает байты файла, но не заменяет доверенный источник, подпись издателя и приёмочный запуск.

macOS

shasum -a 256 /путь/к/файлу

Linux

sha256sum /путь/к/файлу

Windows · PowerShell

Get-FileHash -Algorithm SHA256 "C:\путь\к\файлу"
