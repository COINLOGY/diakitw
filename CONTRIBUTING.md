# Contributing / Участие

Send focused pull requests against main, with tests and a clear description.
Contributions to our own code must be available under MIT; preserve third-party
attribution. Never commit credentials, private configs, SDKs, build caches, signing
keys, personal paths or diagnostic reports. Use example.com and documentation IPs
in fixtures. Do not claim target-OS runtime coverage from static/fixture tests.
See BUILDING.md. iOS is outside this release's scope.
